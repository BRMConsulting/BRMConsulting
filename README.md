# BRM Consulting website

Static website for BRM Consulting (Balance, Resilience, Modernization), served with GitHub Pages at https://brmconsulting.github.io/BRMConsulting/

- `index.html`: all page content (English). Nepali text is in `js/i18n.js`.
- `css/style.css`: design (light green, yellow, pink, sky blue; black Arial text).
- `js/main.js`: navigation, language switch and interactive demos (DMAIC, OEE, SPC, Monte Carlo, EBITDA bridge, working capital, CO2).
- `js/hero3d.js`: 3D animation in the hero (three.js).
- `assets/vendor/`: Chart.js and three.js (MIT licences included).

To add team photos, save them as `assets/team/basant.jpg`, `rajan.jpg`, `manas.jpg`, `kishore.jpg` and replace the initials `<div class="avatar ...">` with `<img class="avatar ..." src="assets/team/....jpg" alt="...">`.

All figures in the demos are illustrative examples.
